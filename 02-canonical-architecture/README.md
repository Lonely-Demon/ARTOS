# 02 — Canonical Architecture

This area contains the Universal Virtual Enterprise architecture and its supporting decomposition artefacts.

- `drafts/` contains versioned blueprint and output-contract documents. `universal-enterprise-blueprint-v2.0.md` is the current design baseline, supplemented by `universal-enterprise-recursive-feedback-clarification-v0.1.md`.
- `capability-and-assembly/` contains the capability ontology, project assembly, governance/evidence/authority, subsystem integration, and staged construction drafts.

The architecture remains a design specification. Any proposed change should state which concern, interface, authority boundary, evidence rule, or lifecycle assumption it changes. Implementation evidence belongs under `05-operating-kernel/` and should not be retroactively inserted into the architecture without a traceable revision.
