# 03 — Enterprise Software Lifecycle

This area contains the enterprise-grade software development and delivery subsystem that receives outputs from the broader Universal Enterprise workflow.

The versioned lifecycle documents are kept together so their evolution is visible. `enterprise-software-lifecycle-v2.0.md` is the current design baseline. `enterprise-software-assurance-operations-v1.md` contains assurance and operational detail, while the practice corpus and research findings preserve the supporting source synthesis.

Research findings are not automatically requirements. Implementation, test, and deployment evidence must be recorded under the operating-kernel or project-specific implementation areas and linked back to the lifecycle rule they validate or challenge.
