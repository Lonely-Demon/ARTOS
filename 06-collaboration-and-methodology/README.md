# 06 — Collaboration and Methodology

This area contains the evidence-reconciled collaboration model, extraction and consolidation protocols, category-space artefacts, reasoning-model analysis, and methods used to understand the user’s preferred way of working.

These documents explain how the enterprise should collaborate with the user and how evidence about that collaboration was derived. They are not a substitute for the user’s current instruction, the canonical architecture, or implementation evidence. When a behavioural inference conflicts with a direct current instruction, the direct instruction governs.
