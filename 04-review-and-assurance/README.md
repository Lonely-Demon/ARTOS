# 04 — Review and Assurance

This area preserves the project’s deliberate attempts to break its own reasoning before implementation or presentation.

- `adversarial-cycles/` contains the ten reviewer-lens cycles and their consolidated change log.
- `improvement-cycles/` contains earlier gap reviews, stress tests, revisions, and stop assessments.

A review record should preserve the challenged assumption, reviewer lens, evidence considered, accepted changes, rejected suggestions, unresolved uncertainty, and downstream artefacts affected. A review is not independent validation merely because it uses a different label; independence must be stated and evidenced.
