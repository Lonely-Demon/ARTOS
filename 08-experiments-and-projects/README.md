# 08 — Experiments and Projects

This area is reserved for active bounded calibrations, isolated worker experiments, and future project runs conducted through the Universal Enterprise workflow.

Each experiment should have its own subdirectory containing a short README, task package or project framing, inputs, generated outputs, evidence state, test results, limitations, and a link to the relevant kernel contract or architecture decision. Do not place an experiment’s runtime database or secrets in version control.

The first real worker-adapter experiment should be created here, while the reusable adapter and contract remain under `05-operating-kernel/`.
